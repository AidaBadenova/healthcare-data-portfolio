#Tech Salary Data Analysis with Pandas
##Project Overview

This project explores salary trends, compensation levels, and company-related insights using Python and Pandas.

The analysis focuses on exploratory data analysis (EDA), salary distributions, and company-level comparisons.

##Topics Covered
Data cleaning
Exploratory Data Analysis (EDA)
Salary distribution analysis
Company analysis
Experience level analysis
Compensation trends
Data visualization
Tools

Python, Pandas, NumPy, Matplotlib, Seaborn
