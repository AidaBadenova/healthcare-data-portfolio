# Healthcare SQL Analytics

## Project Overview
SQL-based analysis of healthcare data demonstrating 
patient visits, diagnoses, physician workload, 
hospitalization trends, and regional healthcare 
utilization.

## Business Problem
Healthcare organizations need data-driven insights to:
- Monitor physician workload and capacity
- Analyze patient flow and visit patterns
- Track hospitalization trends by age and region
- Evaluate MSHI (OSMS) insurance coverage
- Support operational decision-making

## Dataset
Synthetic healthcare dataset containing:
- 1,000 patients across 6 regions of Kazakhstan
- 3,000 patient visits with ICD-10 diagnoses
- Physician specialties and visit costs
- Insurance types including MSHI (OSMS)

## SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- CASE WHEN (age groups, categories)
- JOIN (patients + visits)
- Window Functions (RANK, SUM OVER)
- Subqueries and KPI reporting

## Key Analyses
- Top-10 diagnoses by frequency
- Physician workload and average visit cost
- Regional MSHI coverage analysis
- Age group risk stratification
- Hospitalization statistics
- Patient cohort with chronic conditions

## Business Value
Provides actionable insights for healthcare 
administrators and supports evidence-based 
management decisions in Kazakhstan's healthcare system.

## Tech Stack
Python, SQLite, Pandas, Matplotlib, Seaborn, SQL
